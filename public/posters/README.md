# Posters de juegos

Imágenes de los posters que se muestran en el modo espera
(conductor y pública).

## Archivos esperados

| Juego | Archivo |
|---|---|
| Pictionary | `pictionary.png` |
| Trivia | `trivia.png` |
| Rosco | `rosco.png` |
| Canción Incompleta | `cancion-incompleta.png` |
| Historia Enredada | `historia-enredada.png` |
| Memoria | `memoria.png` |
| Anti-Trivia | `anti-trivia.png` |
| Enlaces | `enlaces.png` |
| ¿Qué Piensa el Público? | `que-piensa-el-publico.png` |
| Placeholder | `placeholder.png` |

## Formato

- PNG con fondo transparente o blanco.
- Tamaño recomendado: 800x600 px.
- Peso máximo: 200 KB.

## Fallback

Si un archivo no existe, se muestra `placeholder.png`.
Si `placeholder.png` tampoco existe, se muestra el alt text.

## Nota

El nombre del archivo se deriva de `juego_codigo` en minúsculas y con
guiones bajos reemplazados por guiones
(`QUE_PIENSA_EL_PUBLICO` → `que-piensa-el-publico.png`).
