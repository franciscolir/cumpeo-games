# Prompts archivados

Cada archivo en esta carpeta corresponde al prompt de un paso cerrado del roadmap.

## Formato de nombre
bloque-{N}-paso-{M}-{slug}.md

Ejemplo: `bloque-1-paso-1-migracion-v3.md`

## Contenido

- Prompt completo entregado al agente externo.
- Evidencia devuelta.
- Resultado de la auditoría.
